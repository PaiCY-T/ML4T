# Task: Dataset Configuration & CSV Parser

## Description
Implement the dataset configuration system by parsing finlab_database_cleaned.csv and creating a robust data specification framework. This system will validate available datasets and their download specifications.

## Acceptance Criteria
- [ ] CSV parser that handles the finlab_database_cleaned.csv format
- [ ] Dataset specification validation with data type checking
- [ ] Dataset catalog system with search and filter capabilities
- [ ] Configuration schema for download specifications
- [ ] Support for both Traditional Chinese and English dataset names
- [ ] Data type mapping and validation (float, int, string)

## Technical Details
- Parse CSV with columns: 資料集名稱, 下載方式及key, 數據類型
- Create `DatasetCatalog` class for managing available datasets
- Implement data type validation and conversion utilities
- Support for multiple download methods: etl, financial_statement, etc.
- Build search functionality by dataset name (both languages)
- Create specification objects for each dataset with metadata

## Dependencies
- [ ] pandas or csv module for parsing
- [ ] Example CSV file: finlab_database_cleaned.csv
